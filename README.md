# Little Links

A small, dependency-free Linktree-style profile page, ready to host on Vercel as a static site.

## Customize

Edit the `defaults` object in `app.js` with your name, bio, image URL, social accounts, and links. Replace the example URLs before sharing. Redeploy to publish your changes to everyone. The **Customize page** button is a local browser preview only; it does not publish changes or sync across devices.

## Run locally

```sh
npx serve .
```

Or serve the folder with any static HTTP server.

## Deploy to Vercel

Import this repository into Vercel, select **Other** as the framework, and deploy with the repository root as the output directory (no build command required). Future changes to the configured production branch can be deployed through Vercel's Git integration.
